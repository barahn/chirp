This is a Chirp relay

It introduces two Chirps to each other, so that one person can help another with their computer. There is nothing to do here in a browser.

Chirp never asks you to type a code into a web page. If someone sent you here to do that, stop: it is not Chirp.

Get Chirp at usechirp.app.
